# Project Progress

## 1. Project Setup & Dataset Selection

* Finalized the project domain: **Indian Startup Ecosystem**.
* Selected the project topic: **Data-Driven Analysis of Success and Failure Factors in Indian Startups**.
* Created the GitHub repository and organized the project structure.
* Selected and added the Indian startup dataset.
* Defined startup outcomes:

  * **Closed** startups are considered failures.
  * **Acquired** and **IPO** startups are considered successful exits.
  * **Operating** startups are excluded because their final outcome is unknown.

## 2. Problem Definition

* Defined the main problem statement.
* Established the objectives of the analysis.
* Identified the major questions to be answered using the dataset.
* Defined the scope and limitations of the project.
* Established the criteria for startup success and failure.

## 3. Data Understanding & Initial Exploration

* Loaded the dataset using **Pandas**.
* Examined the dataset structure, dimensions, columns, and data types.
* Reviewed sample records to understand the available information.

* Identified numerical and categorical variables relevant to the analysis.

## 4. Data Cleaning & Preparation

* Identified missing values and decided appropriate handling strategies.
* Handled missing categorical values in fields such as **Category, Region, and City**.
* Examined and handled missing values in funding-related fields.
* Checked the dataset for duplicate records.
* Analyzed numerical variables for potential outliers.
* Detected and examined outliers in **Funding Total USD** and **Funding Rounds**.

* Prepared the dataset for further analysis.
